Install

SnowyPlover runs in Grasshopper for Rhino 7 and Rhino 8. The video components also need ffmpeg, a free command-line encoder.

SnowyPlover

Install it from the Rhino Package Manager:

  1. In Rhino, run the PackageManager command, or choose Tools › Package Manager.
  2. Search for SnowyPlover, select it and click Install.
  3. Restart Rhino and open Grasshopper. A Snowyplover tab appears, with sections from Camera to Utility.

Updates come through the Package Manager too: open it, find SnowyPlover under Installed, and install the newer version.

ffmpeg

[[FramesToVideo]], [[FramesToGifs]] and [[Join Clips]] call ffmpeg to encode the frames. Everything else works without it.

The quickest way to install it on Windows is from a terminal:

winget install Gyan.FFmpeg

The components look for ffmpeg in this order:

  1. the ffmpegPath input, if you set it (the path to ffmpeg.exe or to its folder),
  2. next to SnowyPlover.gha,
  3. on your PATH,
  4. in the folders where winget installs programs.

If a video component says it cannot find ffmpeg, run where.exe ffmpeg in a terminal and paste the path it prints into ffmpegPath. [[Join Clips]] needs ffmpeg 4.3 or newer for its transitions.

Check that it works

Place [[Get Camera From Viewport]] on the canvas, connect a Boolean Toggle set to True to its activate input, and click Update. Its camera output should show the camera of the active Rhino viewport. Next, read Core concepts.
