Troubleshooting

The viewport does not move when I drag the slider

Click the button on [[Apply Camera]] so it reads Active. It ignores cameras while it is inactive, so that it never takes over the viewport by surprise.

Get Camera From Named Views outputs nothing

Check that the names in the Panel match the Named Views exactly, one per line, and that activate is true. If you edited the Named Views after placing the component, click Update.

The camera jumps between two keyframes

The Named Views probably mix projections, for example one parallel and one perspective. Save them all with the same projection, or right-click [[Apply Camera]] and force one.

Every exported frame looks the same

The t hub is still fed by the slider instead of the master Time output of [[View Capture Driver]], or [[Apply Camera]] is inactive.

The export stopped by itself

[[View Capture Driver]] stops when one of its inputs changes during the export, so one folder never mixes two exports. Click Export Frames again. It also stops with an error when path is empty.

"ffmpeg not found"

Install it with winget install Gyan.FFmpeg, or put the path to ffmpeg.exe in the ffmpegPath input. See Install.

The video plays too fast or too slow

Set frameRate on the video component to the same value as fps on [[View Capture Driver]].

My layers stayed hidden after the animation

Switch [[Apply Design Option]] off with its button: it restores the layer visibility it recorded when you switched it on. If that option was turned off in its right-click menu, use Restore Layers Now from the same menu.

The preview stutters

[[Duration Counter]] plays in real time and skips values when the definition cannot keep up. The export is not affected, because it waits for every frame. To preview faster, preview a lighter version of the model, or scrub with a slider.
