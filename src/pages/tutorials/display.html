Colour and display

The Display components draw in the viewport without baking anything, so whatever they show ends up in the exported frames.

Fading geometry in and out

[[Color Opacity]] turns t into a colour whose transparency changes. [[Color Preview]] draws geometry in that colour. Right-click the mode input to pick the effect: PopUpAndVanish, FadeInAndFadeOut or BreathingEffect.

t   = slider 0.3 live
ev  = EventTimeline [t] events="0.2-0.6"
op  = ColorOpacity [t, red, green, blue, mode]
g   = param Geometry "New wing"
pv  = ColorPreview

t ~> ev.t
ev.event1 ~> op.t
op.Color -> pv.color
g -> pv.geometry

[[Random Color]] gives a list of random colours from a seed, handy for telling many objects apart.

Gradients

[[Gradient Color Curve]], [[Gradient Color Line]] and [[Gradient Color Mesh]] draw geometry with a gradient from color1 to color2. The optional base curve, base line or direction line sets which way the gradient runs.

Text on the viewport

[[Display Text On Viewport]] draws text in screen space, at a pixel position set by XMargin and YMargin, so it stays put while the camera moves. Each item of the list is one line. Use it for titles, captions, or a running timestamp.

title = panel "Option B: courtyard scheme"
txt   = DisplayTextOnViewport

title -> txt.Text

Live outlines

[[Mesh Outline Preview]] draws the silhouette of meshes, breps, extrusions and SubDs as seen from the camera, like Rhino's MeshOutline command but recomputed on every frame.

  • To follow an animation, connect the same camera that goes into [[Apply Camera]]. Do this when exporting frames.
  • With no camera, it follows a Rhino viewport live; the Live button switches that on or off.
  • Right-click it and choose Draw on top of the model to keep the outlines visible through the geometry.
key = AnimateKeyframes [cameras, t]
cam = ApplyCamera [camera]
g   = param Geometry "Massing"
mo  = MeshOutlinePreview [geometry, camera, merge, color, thickness]

key.camera -> cam.camera
key.camera -> mo.camera
g -> mo.geometry
