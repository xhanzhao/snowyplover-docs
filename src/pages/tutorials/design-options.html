Design options

To compare schemes in one animation, put each option on its own Rhino layer. [[Design Option Timeline]] decides which option is visible at each t, and [[Apply Design Option]] switches the layers.

Set up the layers

There are two ways to tell the components which layers are the options:

  • One parent layer. Its direct sub-layers become the options, sorted by name. Put Options::A, Options::B, Options::C under a layer Options and type Options into a Panel.
  • Two or more layers. Each layer you list is one option, in the order you list them.

Wire it

Connect the same Panel to the options input of both components, so they agree on the list. Then wire visibility across and click Apply Design Option's button so it reads Active.

opts = panel "Options"
t    = slider 0.4
dot  = DesignOptionTimeline [options, t, durations, gap]
app  = ApplyDesignOption

opts -> dot.options
opts -> app.options
t ~> dot.t
dot.visibility -> app.visibility

When you click the button to switch it off, Apply Design Option puts every layer back the way it was when you switched it on. Right-click it to turn that off, or to restore the layers right away.

Timing the options

  • durations: a relative weight per option. Empty means all options get the same time.
  • gap: a blank pause between options, in the same unit as durations. 0 is a hard cut. Right-click for a gap at the start or end too.
  • sequence: the order to play them in, by index. 0, 1, 0, 2 shows A, B, A again, then C.
  • domains: exact t ranges, one per sequence item. Connect the domains output of an [[Event Timeline]] to place the options with the timeline bars instead. Durations and gap are then ignored.

Animating inside one option

The progress output has one value per option: 0 before its slot, 0 to 1 during it, and 1 after it. Use it to animate something that belongs to one option, for example arrows that draw themselves only while option B is on screen. Pick the option with List Item, or connect the whole list to an [[Event Timeline]] and choose with its index input.

opts = panel "Options"
t    = slider 0.55
dot  = DesignOptionTimeline [options, t]
ev   = EventTimeline [t, index] events="0-0.5, 0.5-1"
idx  = slider 1 min=0 max=2 digits=0 label="option"
arr  = AnimateArrow [curves, t]

opts -> dot.options
t ~> dot.t
dot.progress ~> ev.t
idx -> ev.index
ev.event1 ~> arr.t

Right-click Design Option Timeline and choose Progress: Null Outside Slot to output nothing outside the slot. Components such as [[Animate Arrow]] then draw nothing at all while their option is hidden.

Blending between options

Design Option Timeline always cuts hard from one option to the next, because a layer is either on or off. For a crossfade, export the same camera move once per option into two folders and join them with a crossfade in [[Join Clips]]. See Join several shots.
