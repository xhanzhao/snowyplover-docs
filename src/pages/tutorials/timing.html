Timing with Event Timeline

One t runs the whole animation, but the camera, the section cut and the arrows should not all start and stop together. [[Event Timeline]] splits t into events, each with its own 0 to 1.

Events

An event is a range of the input t, such as 0.2 to 0.6. Before the range its output is 0, inside it rises from 0 to 1, and after it it stays at 1. Drag the slider:

t  = slider 0.45 live
ev = EventTimeline [t] events="0-0.4, 0.3-0.7, 0.6-1"
a  = param Number "camera"
b  = param Number "section"
c  = param Number "arrows"

t ~> ev.t
ev.event1 ~> a
ev.event2 ~> b
ev.event3 ~> c

On the canvas, Event Timeline draws its events as bars. Drag a bar to move it, drag its ends to resize it, and use + and − to add or remove events; each event gets its own output, event 1, event 2… Hold Shift while dragging to turn off snapping.

Easing

Right-click the component to pick the easing for all its events: Linear, Ease In, Ease Out or Ease In-Out. Ease In-Out is the one to use for camera moves, because the camera starts and stops gently. The slider below drives the same events with Ease In-Out; compare the numbers with the diagram above.

t  = slider 0.45 live
ev = EventTimeline [t] events="0-0.4, 0.3-0.7, 0.6-1" ease=inout
a  = param Number "camera"
b  = param Number "section"
c  = param Number "arrows"

t ~> ev.t
ev.event1 ~> a
ev.event2 ~> b
ev.event3 ~> c

The right-click menu has two more settings:

  • Outside Event: Hold outputs 0 before the event and 1 after it. Null Outside outputs nothing, which hides geometry that should only appear during its event.
  • Snap: snaps the bars to 0.1 s, 0.5 s, 1 s or one frame while you drag. It needs duration (the animation length in seconds), and fps for frame snapping. Both are only used to display and snap the bars; they do not change the outputs.

Nesting

Any event output is itself a 0 to 1, so it can feed another Event Timeline. Use this to split one part of the animation further, for example three arrows that appear one after another inside the "arrows" event. The eventSeconds output gives the length of each event in seconds, which you can wire into the nested timeline's duration so its snapping stays in seconds.

t   = slider 0.8 live
ev  = EventTimeline [t] events="0-0.6, 0.6-1"
sub = EventTimeline [t] events="0-0.5, 0.25-0.75, 0.5-1"

t ~> ev.t
ev.event2 ~> sub.t

Preview in real time

A slider shows one moment at a time. To watch the animation play at its real speed, feed the t hub from [[Duration Counter]]. Set totalDuration to the same length as [[View Capture Driver]], click Play, and the counter runs from 0 to 1 in that many seconds. Pause holds it, Reset goes back to the start.

len = slider 8 min=1 max=30 digits=0 label="seconds"
dc  = DurationCounter [totalDuration, fps]
hub = param Number "t"
ev  = EventTimeline [t, duration] events="0-0.6, 0.5-1"

len -> dc.totalDuration
len -> ev.duration
dc.t_Counter ~> hub
hub ~> ev.t

A heavy definition may not keep up with 30 fps. The counter then skips values, so the preview looks choppier than the export will be. The exported frames are always complete, because [[View Capture Driver]] waits for every frame.
