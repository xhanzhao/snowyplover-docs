Export frames and video

Exporting happens in two steps. [[View Capture Driver]] saves one image per frame into a folder. A video component then encodes that folder with ffmpeg.

Capture the frames

vcd = ViewCaptureDriver
hub = param Number "t"
dir = panel "D:\anim\shot01"

dir -> vcd.path
vcd.masterTime ~> hub
  • totalDuration × fps is the number of frames. 8 s at 30 fps is 240 frames.
  • path is the output folder. Use a new folder per shot; the video components read every frame with the same base name in it.
  • viewName picks the viewport; empty means the active one.
  • width and height fix the image size; 0 uses the viewport size.
  • baseName names the files: keyframe_000000.jpg, keyframe_000001.jpg…
  • transparent saves PNGs with a transparent background, for compositing in After Effects or Premiere.

Connect master Time to the t hub and click Export Frames. The component shows its progress, and done turns true at the end. If you change one of its inputs while it runs, it stops, so that one folder never mixes two exports.

Turn on [[Apply Camera]] and [[Apply Design Option]] before you export. While they are inactive, the viewport does not follow the animation, and every frame looks the same.

Make a video

[[FramesToVideo]] encodes the folder. Set frameRate to the fps you exported with.

  • MP4 (H.264) plays everywhere. quality is the CRF value: 18 looks nearly lossless, 23 is ffmpeg's default, and higher numbers mean smaller files.
  • MOV (ProRes 4444) keeps the transparency of PNG frames. The files are large.

[[FramesToGifs]] makes a GIF instead. gifFps (15 by default) and width keep the file small; loop is 0 to loop forever.

dir = panel "D:\anim\shot01"
fv  = FramesToVideo [folder, frameRate, format, quality]
fg  = FramesToGifs [folder, gifFps, width]

dir -> fv.folder
dir -> fg.folder

Both write next to the frames by default (keyframe.mp4, keyframe.gif); set output to write somewhere else. Click the button again while they run to cancel.

Join several shots

A presentation film is usually several shots: an aerial, an orbit, a section, an interior. Export each into its own folder, then list the folders in [[Join Clips]].

dirs = panel "D:\anim\shot01\nD:\anim\shot02\nD:\anim\shot03"
tr   = panel "1"
jc   = JoinClips [folders, transitions, transitionSeconds, fadeIn, fadeOut]

dirs -> jc.folders
tr -> jc.transitions
  • transitions: one value for every join, or one per join. 0 is a cut, 1 a crossfade, 2 and 3 fade through black or white, 4 dissolves, 5 to 12 are wipes, slides and circles. Right-click the input to pick by name.
  • transitionSeconds: how long each transition lasts. The clips overlap by this much, so the film gets shorter.
  • fadeIn and fadeOut fade from and to black at the start and end.

Clips of a different size are fitted into the size of the first clip with black bars.

Example: crossfade between two design options

[[Design Option Timeline]] can only cut from one option to the next, because a Rhino layer is either on or off. To let option A dissolve into option B while the camera keeps moving, export the same camera move twice, once with each option visible, and join the two folders with a crossfade.

The two clips must overlap by the length of the crossfade, so that the camera is in the same place on both sides of the blend. Say the whole move takes 10 seconds, the switch happens halfway, and the crossfade lasts 1 second:

ClipVisible optionPart of the move (t)totalDurationFolder
AA0 to 0.555.5D:\anim\optionA
BB0.45 to 15.5D:\anim\optionB

Joined with a 1-second crossfade, the clips overlap from t = 0.45 to 0.55, and the film is 5.5 + 5.5 − 1 = 10 seconds long again.

1. Export clip A

[[View Capture Driver]] always runs master Time from 0 to 1, so remap it to the part of the move this clip covers before it reaches the t hub. Grasshopper's own Remap Numbers does this: set Source to 0 To 1 and Target to 0 To 0.55. To show only option A, feed [[Apply Design Option]] a fixed visibility list instead of Design Option Timeline: True, False. Switch it to Active and click Export Frames.

len  = panel "5.5"
dirA = panel "D:\anim\optionA"
vcd  = ViewCaptureDriver [totalDuration, path]
src  = panel "0 To 1"
tgt  = panel "0 To 0.55"
rm   = native "Remap Numbers" in="Value, Source, Target" out="Mapped"
hub  = param Number "t"
key  = AnimateKeyframes [cameras, t]
cam  = ApplyCamera [camera]
opts = panel "Options"
vis  = panel "True\nFalse"
app  = ApplyDesignOption

len -> vcd.totalDuration
dirA -> vcd.path
vcd.masterTime ~> rm.Value
src -> rm.Source
tgt -> rm.Target
rm.Mapped ~> hub
hub ~> key.t
key.camera -> cam.camera
opts -> app.options
vis -> app.visibility

2. Export clip B

Change three things and export again: Target to 0.45 To 1, the visibility to False, True, and path to D:\anim\optionB. Keep totalDuration at 5.5 and the same fps.

3. Join them with a crossfade

List both folders in [[Join Clips]], set transitions to 1 (crossfade) and transitionSeconds to the overlap, 1. Click Join Clips.

dirs = panel "D:\anim\optionA\nD:\anim\optionB"
tr   = panel "1"
ts   = panel "1"
jc   = JoinClips [folders, frameRate, transitions, transitionSeconds]

dirs -> jc.folders
tr -> jc.transitions
ts -> jc.transitionSeconds

The same recipe works for more options: export one clip per option, overlapping each neighbour by the length of the crossfade, and list all the folders in order.
