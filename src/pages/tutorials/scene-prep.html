Preparing the scene

The Utility components, and Box Mapping Each, run once before you animate. They write to the Rhino document, so each has a Bake button, and nothing happens until you click it.

Layers and materials

  • [[Randomly Assign Object To Layers]] bakes geometry onto a set of new layers, Layer_01, Layer_02…, each object on a random one and each layer with a random colour. If the layers exist already, they are updated. Use it to give a massing model some variety, or to split it into groups you can animate separately.
  • [[Assign Materials By Layers]] makes a render material from each layer's colour, assigns it to the layer, and sets the objects to use the material by layer. Use skipLayersName to leave out layers whose path contains a given word.
g   = param Geometry "Massing"
rl  = RandomlyAssignObjectToLayers [geometries, baseLayerName, layerCount]
am  = AssignMaterialsByLayers

g -> rl.geometries

Texture mapping

[[Box Mapping Each]] gives every object its own box mapping, with optional random scale, offset and rotation, so a material such as brick or timber does not repeat identically on every block. Turn on bake, or click Bake, to apply it to the referenced Rhino objects.

Small helpers

  • [[Read Slider Domain]] reads the minimum, maximum and current value of a Number Slider, for remapping.
  • [[Domain Partition]] divides a domain into equal parts and remaps a value into the part it falls in.
