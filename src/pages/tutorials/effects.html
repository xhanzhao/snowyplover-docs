Animating the model

The Effect components animate geometry with t. They all follow the same pattern: geometry and t in, animated geometry out. Nothing is baked: the result shows as a Grasshopper preview, and the Display components can colour it.

Section cuts

[[Animate Section Cut]] sweeps a cutting plane through the geometry as t goes from 0 to 1. The plane sets the direction of the cut (world XY by default); flip reverses it, and KeepNegative keeps the other side.

g   = param Geometry "Building"
t   = slider 0.5
cut = AnimateSectionCut

g -> cut.geometry
t ~> cut.t

With Union off, every object is cut over its own height, so a short and a tall building finish at the same time. Turn it on to cut the whole group as one.

To cut with a real Rhino clipping plane instead, so that the rendered view clips too, use [[Animate Clipping Plane]]: give it the clipping plane's id and a plane to move it to. [[Deconstruct Clipping Plane]] reads the current plane of a clipping plane.

Growing curves and surfaces

  • [[Animate Curve]] draws curves along their length as t goes from 0 to 1. Right-click mode to grow from the start, or from the middle outwards.
  • [[Animate Surface]] grows surfaces along U (tU) and V (tV), from an edge or from the centre.
  • [[Animate Arrow]] draws an arrow along each curve, with solid, dotted or dashed lines. It is made for circulation diagrams and site flows.
  • [[Jitter Curve]] returns points along a curve, each moved a random distance. Draw a curve through them for a hand-drawn look.
t   = slider 0.35 live
ev  = EventTimeline [t] events="0-0.5, 0.5-1"
c   = param Curve "Paths"
arr = AnimateArrow [curves, t, lineType, arrowLength]

t ~> ev.t
c -> arr.curves
ev.event1 ~> arr.t

Moving and scaling objects

  • [[Scale Animated Geometry]] grows geometry from nothing to full size around a Center point.
  • [[Animate Objects Move]] moves an object between two positions you record. Move it to the start and click set A, move it to the end and click set B, then drive t. With apply on it moves the Rhino object itself; reset puts it back.
  • [[Animate Objects On Curves]] spreads objects such as cars or people along curves (each branch of the tree is one path). It outputs planes and an index per object, which you use to orient blocks. Turn on animate and drive t to make them travel.
roads = param Curve "Roads" access=tree
len   = panel "4.5\n6.0"
rat   = panel "3\n1"
on    = toggle true label="animate"
t     = slider 0.2
cars  = AnimateObjectsOnCurves [curves, objectLengths, ratios, animate, t]

roads -> cars.curves
len -> cars.objectLengths
rat -> cars.ratios
on -> cars.animate
t ~> cars.t
